<h1 align="center">🗳 Chandigarh University CR Voting System</h1>

<h3 align="center">
A Modern Web-Based Voting Management System Built Using Flask
</h3>

<hr>

<h2>📌 Project Overview</h2>

<p>
The Chandigarh University CR Voting System is a web-based election platform developed using Python Flask. 
It allows students to cast votes securely for Class Representative (CR) elections while providing a secure admin dashboard for candidate management and election monitoring.
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
    <li>✔ Secure Student Voting System</li>
    <li>✔ Admin Authentication</li>
    <li>✔ Add/Delete Candidates</li>
    <li>✔ Duplicate Vote Prevention</li>
    <li>✔ Winner Declaration System</li>
    <li>✔ Live Result Display</li>
    <li>✔ Responsive Modern UI</li>
    <li>✔ SQLite Database Integration</li>
</ul>

<h2>⚙ Installation Steps</h2>

<h3>1️⃣ Clone Repository</h3>

<pre>
git clone https://github.com/YOUR_USERNAME/CU_CR_Voting_System.git
</pre>

<h3>2️⃣ Open Project Folder</h3>

<pre>
cd CU_CR_Voting_System
</pre>

<h3>3️⃣ Install Flask</h3>

<pre>
pip install flask
</pre>

<h3>4️⃣ Run Project</h3>

<pre>
python app.py
</pre>
